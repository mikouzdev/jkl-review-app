# User stories

## MVP

- As a user, I want to rate Jyväskylä districts based on specific criteria.

- As a user, I want to see the rating criteria, so that I know what aspects I'm evaluating.

- As a user, I want to add a text comment to my rating, so I can explain my views better.

- As a user, I want to see a list of all Jyväskylä districts, so I can choose which one to rate.

- As a user, I want to register and log in, so my ratings are saved on my account.

- As a user, I want to view ratings for a specific district, so that I can see what other people think about the area.

- As a user, I want to see a leaderboard of top-rated districts for each criterion, so that I can find the best area for that criteria.

- As a user, I want to see a average rating for each district, so that I can compare areas easily.

- As a user, I want to see all my submitted ratings, so I can see what I've rated before.

- As a logged-in user, I want to update my ratings, so that I can correct or improve my previous rating.

- As a logged-in user, I want to delete my ratings, so that I can remove feedback I no longer want visible.

- As an admin, I want to delete user ratings, so that I can moderate inappropriate reviews.

- As an admin, I want to edit user rating comments, so that I can correct or moderate reviews.

## EXTRA

- As a user, I want to see a map of the district I'm rating, so I can better identify its location and surroundings.

- As a user, I want to search for a district by name, so that I can quickly find the area I want to rate or view.

- As a user, I want to filter districts by criteria, so that I can focus on what matters to me.
